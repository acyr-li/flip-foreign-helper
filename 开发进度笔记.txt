【今天挖出并修掉的 11 个 bug（按危害排序）】

1. 正则误删英文单词字母   ★★★ 最严重
   [regex]::Replace($clean, '[A-Da-d]\s*[.、．:：·]?', '')
   本意去 "A." 前缀，实际把单词里所有 a/b/c/d 全删掉：
     raw -> rw   (2 字符被当无效)      recreation -> reertion
     cell -> ell                        reconsider -> reonsier
   测试题选项全是英文单词 -> 几乎每题被破坏 -> 整页 UNKNOWN
   单词卡包是中文选项不含 a-d，所以一直没暴露。
   修复：只删开头带标点的前缀 '^\s*[A-Da-d]\s*[.、．:：·]\s*'

2. Rapid 与 Windows OCR 结果合并   ★★★
   原逻辑：谁行数多用谁当主，另一套补漏 -> Windows 乱码污染正确结果
   实测同一张图：Rapid「n.混合；结合体；混合物」/ Windows「结合体·：曰厶n·匕口，匕口」
   修复：Rapid 有结果(≥3行)就独占使用，绝不合并；仅在 Rapid 失败时退回 Windows

3. 选项长度下限设为 3   ★★
   合法短词 hi(2字符) 被判"过短"，整题作废 -> 反复 UNKNOWN
   修复：下限改为 2；题干下限改为 1

4. 点完选项等 3.4 秒才抓图   ★★
   实测：对错标记只在 0.5~2.0 秒内出现，之后立即翻页
   修复：0.7 秒抓图 + 再等 2.2 秒读屏判断是否翻页

5. 颜色阈值 35%   ★★
   实测绿勾区只占 21.58%，阈值 35% 永远判不出
   修复：阈值降到 15%（绿勾区实际 93~100%，余量充足）

6. 绿色按钮被当成绿勾   ★★
   点完页面已翻到结算页，把绿色「确定」按钮认成绿勾 -> 答对被判成答错
   （ministry=部 选对了 B，却报"正确答案 C mile"；release=释放 也误判）
   修复：抓图后先用题干区指纹确认还是同一题，变了就放弃颜色判定

7. 答题页按系统返回键   ★★
   Do-Home 无脑按返回 -> 退出小程序 -> 退到桌面/抖音乱点
   修复：QUIZ/LEARN 状态直接返回不动；回首页改为点左上角返回箭头

8. 做完一个卡包就退出   ★
   修复：Do-Words 在卡包列表循环找「开始/继续」，找不到就点卡包卡片本身（文字 y+110）

9. 依据首页卡片"已完成 N/N"跳过模块   ★
   首页那行和"测试/单词"在 OCR 里挨得近，正则张冠李戴 -> 整个模块被跳过
   修复：一律进列表逐个确认，不做推断

10. 乱码门槛过严   ★
    "连续2个特殊符号=乱码" 把正常题干「给··打蜡」误杀
    修复：门槛改为 3 个以上；真乱码靠"匕/囗/丷/丶/丨"等生僻错字识别

11. 点「开始」后立刻做题   ★
    读到加载中的页面，状态不是 QUIZ，Run-Quiz 直接返回 0 题
    修复：点完轮询读屏最多 6 次，确认状态确实是 QUIZ 才开始


【点击坐标的确定值（实测校准，别随意改）】
  横向：屏幕宽度 × 0.4（用户确认：整行可点，除两侧边缘）
  纵向：选项文字顶部 + 25
        实测（小米 1080x2400）OCR 文字顶部 1249/1409/1568/1722
        分隔线推算行中心 1260/1416/1572/1728，差值恒为 24~29
  越界保护：算出的点若 <5% 或 >93% 屏高，先小幅滚动再重新定位

  实测（vivo 1440x3200）选项在下半屏时：A=1662 B=1874 C=2085 D=2293，行距约 210


【两种模块的行为差异（必须区分）】
  测试模块：点选项 -> 自动翻到下一题，标记只出现 0.5~2 秒
  单词模块：点选项 -> 变绿勾/红叉 -> 必须上滑才翻页


【七道关卡（能对的就做，稍有不确定就停）】
  · 数据脏（乱码/选项不全/重复/过短）  -> 停，打印原因
  · 判不出答案                          -> 停，打印题干+四选项
  · 答错（绿勾不在我点的位置/我点的有红叉）-> 停，标出错选和正确答案
  · 点了没翻页也没标记                  -> 补点一次，仍不行才停
  · 识别不出题目                        -> 停，打印页面文字
  · 弹窗点 4 次不消失                   -> 停
  · 手机连续 12 次读不到屏幕            -> 停，提示插线
