连上手机后能自动把「翻转外语」小程序今天的任务做完
（两个测试 + 两个单词词本）。你只需要双击一下。
不需要 root、不需要改手机设置。


──────────────────────────────────────────────────────────────
 第一步：让电脑能连上手机（只需做一次）
──────────────────────────────────────────────────────────────
1. 手机「设置」→「关于手机」→ 连续点 7 次「版本号」→ 提示进入开发者模式
2. 返回上一级 →「开发者选项」→ 打开「USB 调试」
3. 数据线连电脑（必须能传数据，纯充电线不行）
4. 手机弹「是否允许 USB 调试」→ 勾「一律允许」→ 确定
   没弹就拔掉重插一次


──────────────────────────────────────────────────────────────
 第二步：小程序停在首页
──────────────────────────────────────────────────────────────
微信 → 打开「翻转外语」→ 停在「今日任务」页面
运行期间手机别熄屏、别切 App。


──────────────────────────────────────────────────────────────
 第三步：双击运行
──────────────────────────────────────────────────────────────
双击  一键完成今日任务.bat

窗口会滚动显示进度，例如：
   OCR: RapidOCR（高精度）已就绪
   [0] fry -> D (AI)
   [1] artificial -> A (AI)

跑完显示「=== 完成，用时 xxx 秒 ===」。


──────────────────────────────────────────────────────────────
 ★ 建议做两件事（直接决定正确率）
──────────────────────────────────────────────────────────────

【一】装高精度 OCR —— 决定单词卡包能不能做对

单词卡包的题干是大字号英文（比如 fry），Windows 自带 OCR 读不出来。
装了 RapidOCR 才能准确识别。

做法：双击  安装OCR组件.bat
  · 电脑有 Python → 自动装好，1-3 分钟
  · 电脑没 Python → 会提示二选一：
      - 去 python.org 装 Python（安装时务必勾 "Add python.exe to PATH"）
      - 或者不装直接用：50 题测试没问题，单词卡包偶尔出错

怎么确认：运行时窗口出现
    OCR: RapidOCR（高精度）已就绪     ← 装好了
    OCR: 使用 Windows 内置…          ← 没装


【二】填 AI 判题密钥 —— 决定判题准不准

做法：双击  设置AI密钥.bat → 粘贴 key → 回车（会自动联网验证）

怎么拿 key：
  1. 浏览器打开 https://platform.deepseek.com
  2. 注册登录 → 左侧「API keys」→「创建 API key」
  3. 复制 sk- 开头那串（只显示一次，先存记事本）
  4. 充值，最低 10 元。判一道题约 0.0003 元，一年五六块钱


──────────────────────────────────────────────────────────────
 常见问题
──────────────────────────────────────────────────────────────
Q：窗口说「手机没有连上」
A：换根数据线 → 确认 USB 调试开着 → 手机上点了「允许」

Q：卡在某个页面不动
A：脚本会把那屏截图存到 logs\unknown_*.png，把这文件发给我

Q：单词词本做到一半停了
A：多半是 OCR 组件没装，先跑「安装OCR组件.bat」

Q：会不会把我账号搞坏
A：只做截图和模拟点击。不登录、不改密码、不碰支付。

Q：会判错吗
A：配齐 OCR + AI key 后，测试题和单词题都用真题验证过。

 文件夹里都是什么
──────────────────────────────────────────────────────────────
一键完成今日任务.bat   ← 平时双击这个
安装OCR组件.bat        ← 装高精度 OCR（建议）

data\state.json        ← 做过的题的记忆，别删
logs\                  ← 运行记录和异常截图
使用说明.txt           ← 更详细的说明
导出给别人.bat         ← 可以再转给别人（会自动清 key）
