========================================================================
  翻转外语 · 今日任务自动完成助手   v2.1
========================================================================

【它能干什么】
连上手机后自动完成「翻转外语」小程序今天的任务：
  · 两个 50 题测试
  · 两个 25 词单词词本（学习 → 强化 → 完成）
听力不做。

它会自己看屏幕、判题、点击、翻页。
判题用 DeepSeek AI；识别优先用 RapidOCR，退回 Windows 自带 OCR。


------------------------------------------------------------------------
【第一次用：三步】
------------------------------------------------------------------------
1. 手机打开「开发者选项」→ 开启「USB 调试」
   （设置 → 关于手机 → 连点版本号 7 次 → 返回 → 开发者选项）

2. 数据线连电脑，手机弹「允许 USB 调试」→ 勾「一律允许」→ 确定

3. 微信打开「翻转外语」，停在「今日任务」页

双击「一键完成今日任务.bat」。


------------------------------------------------------------------------
【两个可选组件（强烈建议，直接决定正确率）】
------------------------------------------------------------------------

① 安装OCR组件.bat —— 装 RapidOCR 高精度识别
   为什么：单词词本的题干是大字号英文（如 fry），Windows 自带 OCR
           完全读不出来（已实测：同一张图，中文选项能识别，英文题干 0 行）
   怎么做：双击，自动 pip 安装（需要电脑有 Python）
   验证：运行时窗口显示「OCR: RapidOCR（高精度）已就绪」

② 设置AI密钥.bat —— 填 DeepSeek 密钥
   为什么：保证判题准确率（真题验证 18/18 全对）
   怎么做：双击 → 粘贴 sk- 开头的 key → 回车，自动联网验证
   拿 key：https://platform.deepseek.com → 注册 → API keys → 创建
           充值最低 10 元，判一题约 0.0003 元


------------------------------------------------------------------------
【程序结构】
------------------------------------------------------------------------
一键完成今日任务.bat    入口
安装OCR组件.bat         装高精度 OCR（→ 安装OCR组件.ps1）
设置AI密钥.bat          填/换/清空密钥（→ setup_key.ps1）
导出给别人.bat          复制干净副本（自动清 key）
flip2.ps1               主程序
ocr_helper.py           RapidOCR 常驻服务
config.json             AI 配置
bin\adb.exe             手机连接工具（内置）
data\state.json         题库缓存（会变大，别删）


------------------------------------------------------------------------
【工作原理（为什么换主题/换分辨率都能用）】
------------------------------------------------------------------------
· 不依赖颜色：状态判断全部来自 OCR 文本
· 不依赖分辨率：点击位置取文字实际坐标，翻页手势按屏幕百分比
· 选项定位：用「4 行等距」这个特征识别，比正则匹配字母更可靠
· 题干识别：RapidOCR 优先，读不到时放大/二值化多种手段补
· 答题流程：点选项 → 等结果动画 → 上滑下一题
· 答错重考：记住已试过的选项，重考时换一个


------------------------------------------------------------------------
【排查】
------------------------------------------------------------------------
· 「手机没有连上」→ 换线 / 确认 USB 调试 / 手机上点允许
· 卡在某页 → logs\unknown_*.png 是现场截图
· 单词词本停了 → 先跑「安装OCR组件.bat」
· 想只用本地词典 → config.json 里 "use_ai" 改 false
· 只看不动手机 → powershell -ExecutionPolicy Bypass -File flip2.ps1 -Mode check
