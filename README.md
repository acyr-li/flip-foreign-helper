# 翻转外语 今日任务自动助手

连上安卓手机后，自动完成「翻转外语」小程序的每日任务（测试 + 单词词本）。

## 需要什么

- Windows 10 / 11
- 安卓手机 + 数据线（能传数据的，纯充电线不行）
- Python 3.9+（用于 OCR 组件，可选但强烈建议）
- 一个 DeepSeek API Key（可选，用于 AI 判题，约 0.0003 元/题）

## 三步上手

1. **双击 `安装OCR组件.bat`**
   装 RapidOCR。不装的话单词词本的英文题干识别不出来，会做错。
   需要电脑有 Python，没有的话会提示你去 python.org 装。

2. **双击 `设置AI密钥.bat`**
   粘贴你的 DeepSeek key（`sk-` 开头）。到 https://platform.deepseek.com 注册后创建。
   充值最低 10 元，够用很久。

3. **双击 `一键完成今日任务.bat`**
   手机先打开「翻转外语」小程序，停在「今日任务」页。

## 手机准备

- 设置 → 关于手机 → 连点 7 次版本号 → 进入开发者模式
- 设置 → 开发者选项 → 打开「USB 调试」
- 数据线连电脑，手机上弹「允许 USB 调试」→ 勾「一律允许」

## 怎么知道配置对了

启动后窗口应该显示：

```
翻转外语 今日任务 v2.4  构建 11-01 14:42
OCR: RapidOCR（高精度）已就绪
AI 判题已启用: deepseek-chat
```

第二行如果是 `OCR: 使用 Windows 内置`，说明 OCR 组件没装好，去跑第 1 步。

## 它会做什么

```
--- 1/2 测试 ---
  进测试模块，读「今日进度 N/M」
  没满就点开始做题
--- 2/2 单词 ---
  进卡包列表，逐个卡包做（学习 + 强化）
```

## 安全设计

遇到下面这些情况会**立刻停下**，不会瞎猜：

- 识别不出题目 / 题干有乱码
- 判不出答案
- 答错了（会打印出你选的和对的）
- 点了没反应
- 弹窗关不掉
- 手机断开

停下时窗口会打印原因和题目，你手动处理完再重新双击即可。

## 文件说明

| 文件 | 作用 |
|---|---|
| 一键完成今日任务.bat | 主入口 |
| 安装OCR组件.bat | 装 RapidOCR |
| 设置AI密钥.bat | 填 / 换 / 清空 key |
| 清空分享包密钥.bat | 清空 key 并全盘扫描残留 |
| 导出给别人.bat | 生成干净副本（自动清 key） |
| flip2.ps1 | 主程序 |
| ocr_helper.py | OCR 常驻服务 |
| bin\adb.exe | 安卓调试桥（已内置） |
| 开发进度笔记.txt | 开发记录、已知问题 |
